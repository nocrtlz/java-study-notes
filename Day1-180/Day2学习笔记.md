# Day2学习笔记

OOP（面向对象编程）的四大核心特性是：**抽象、封装、继承、多态**。

### 1. 抽象（Abstraction）

**核心：抓共性、藏细节，只关注与目标相关的核心特征** 抽象就是从具体事物中提取出共同的、本质的属性和行为，忽略无关的细节，只定义 “有什么功能”，不关心 “功能具体怎么实现”。

- 你的代码体现： 你把所有商品（手机、书本）共有的 `id、name、price` 属性和 `showInfo()` 行为抽出来做成 `Goods` 父类，这就是抽象。你不需要关心具体是手机还是书，只需要知道 “商品都有这些属性、都能展示信息”。
- Java 实现方式：抽象类（`abstract class`）、接口（`interface`）
- 作用：降低认知复杂度，统一业务规范，让代码聚焦核心逻辑。

------

### 2. 封装（Encapsulation）

**核心：属性私有化，行为公开化，控制访问权限** 封装就是把类的内部数据（成员变量）隐藏起来，外部代码不能直接读写，只能通过类对外提供的公共方法来访问和操作。

- 你的代码体现： `Goods` 里的 `id、name、price` 都用 `private` 修饰，外部只能通过 `getId()、setPrice()` 等方法读写，这就是标准的封装实现。
- Java 实现方式：`private` 修饰成员变量 + 公共 getter/setter 方法
- 作用：
  - 保证数据安全（可以在 setter 里加合法性校验）
  - 隐藏内部实现细节，外部只需要调用方法
  - 降低代码耦合，内部逻辑修改不影响外部调用

------

### 3. 继承（Inheritance）

**核心：子类复用父类代码，扩展自身特性** 继承是让子类（派生类）直接拥有父类（基类）的所有属性和方法，同时可以添加自己独有的属性和方法，实现代码复用。

- 你的代码体现： `Phone` 和 `Book` 用 `extends Goods` 继承了父类，不用再重复写一遍 `id、name、price` 和对应的 get/set 方法，只需要添加自己的 `brand`、`author` 属性即可。
- Java 实现方式：`extends` 关键字（Java 是单继承，一个类只能有一个直接父类）
- 作用：大幅减少重复代码，建立清晰的类层级结构。

------

### 4. 多态（Polymorphism）

**核心：同一个方法调用，不同对象有不同的实现** 多态是指同一种方法调用，根据对象的实际类型不同，会执行完全不同的逻辑。

#### 字符串：给定字符串，统计大写字母、小写字母、数字的个数

```
public class StringCount {
    public static void main(String arg[]){
        String t="Hello 12345 Java 6666";
        StrCount(t);
    }
    //计数
    public static void StrCount(String str){
        int upper=0;
        int lower=0;
        int digit=0;
        for(int i=0;i<str.length();i++){
            char ch=str.charAt(i);
            //Character.isUpperCase();获取是否为大写字母
            if(Character.isUpperCase(ch)){
                upper++;
            }else if(Character.isLowerCase(ch))
            {
                lower++;
            }else if(Character.isDigit(ch))
            {
                digit++;
            }
        }
        System.out.println("upper="+upper+" lower="+lower+" digit="+digit);
    }
}
```

#### 数组：写方法，接收 int 数组，返回数组最大值

```
public class ArrMax {
    public static void main(String[] age){
        int[] arr={1,8,4,5,2,8,9,10};
        System.out.println(max(arr));
    }

    public static int max(int[] a){
        int max=a[0];
        for(int i=0;i<a.length;i++){
            if(a[i]>max){
                max=a[i];
            }
        }
        return max;
    }
}
```

##### 字符串长度是 `str.length()`（带括号的方法），数组长度是 `arr.length`（不带括号的属性）

##### 求最大值不要初始化 `max = 0`，如果数组全是负数结果就会出错，必须用数组元素本身做初始值

##### 遍历数组注意下标范围是 `0 ~ arr.length-1`，避免触发数组越界异常

1. ##### **`max` 带 `static` 时**`max` 也是静态方法，同一个类里的静态方法之间可以直接互相调用，所以 `max(arr)` 能正常运行。

2. ##### **`max` 去掉 `static` 时**`max` 变成了「实例方法」，它必须依附于对象才能存在。而静态的 `main` 方法执行时，还没有创建任何对象，因此找不到 `max` 方法，直接编译报错。

##### `static` 静态方法属于**类本身**类加载时就存在，不需要创建对象，直接就能调用无 static 实例方法属于**类的对象**必须先 `new` 出一个对象，通过对象才能调用

##### 静态只能直接调静态，调非静态必须先创建对象。

## ❓ 当天 3 个自测思考题

##### 方法重载和方法重写的区别，分别发生在什么场景？

| 对比维度       | 方法重载（Overload）                 | 方法重写（Override）                 |
| -------------- | ------------------------------------ | ------------------------------------ |
| **发生位置**   | 同一个类内部                         | 子类和父类之间（必须有继承）         |
| **方法名**     | 必须相同                             | 必须相同                             |
| **参数列表**   | 必须不同（个数 / 类型 / 顺序）       | 必须完全相同                         |
| **返回值**     | 无要求（不参与重载区分）             | 必须兼容（基础阶段认为必须相同）     |
| **访问修饰符** | 无要求                               | 不能比父类更严格                     |
| **注解**       | 不需要特殊注解                       | 推荐加 `@Override`                   |
| **核心目的**   | 同名方法提供多种参数调用，提升易用性 | 子类改写父类逻辑，实现多态           |
| **多态类型**   | 编译时多态（编译期就确定调用哪个）   | 运行时多态（运行时根据对象类型决定） |

##### private 关键字作用是什么？封装的意义是什么？

`private` 是 Java 中**最严格的访问权限修饰符**，字面意思是 “私有的”，核心作用是**限制访问范围，实现信息隐藏**，它是实现封装的核心工具。

封装是面向对象四大特性之一，通俗来说就是：**把内部数据和实现细节藏起来，只对外暴露安全、可控的访问入口**

**多态的前提是什么？`Father f = new Son();` 这个引用能不能调用子类独有的方法？为什么？**

多态（运行时多态）的形成必须同时满足以下三个条件，缺一不可：

1. **存在继承关系** 必须有父类和子类的层级结构（`extends`），这是多态的基础。
2. **子类重写父类的方法** 子类必须对父类中的方法进行 `@Override` 重写，拥有自己不同的实现逻辑。如果子类不重写，调用的还是父类原方法，就体现不出 “多种形态”。
3. **父类引用指向子类对象（向上转型）** 语法格式就是你问的 `Father f = new Son();`，左边声明父类引用，右边创建子类对象。这是多态的语法表现形式。
