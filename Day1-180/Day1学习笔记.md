### 练习题

数组遍历：定义 int 数组`{10,20,30,40}`，循环打印所有元素，计算数组总和

```
public class Day1 {
    public static void main(String[] args) {
       //数组是直接.length
        int[] a={10,20,30,40};
        int sum=0;
        for(int i=0;i<a.length;i++) {
            System.out.println(a[i]);
            sum+=a[i];
        }
        System.out.println(sum);
    }
}
```

```
public class Day1 {

        //获取字符串长度是.length（）
       String s="hello";
       int l=s.length();
       System.out.println(l);
       for(int i=0;i<l;i++){

       }
    }
}
```

### 自测问题

### 1. 为什么数组用 `length` 属性，字符串用 `length()` 方法？

核心原因是**两者的本质与面向对象设计原则不同**：

- 数组是 Java 中的**特殊引用类型**，不属于普通类。数组一旦创建，长度就固定不变，`length` 是数组与生俱来的固有属性（字段），直接存储在数组的对象结构中，因此可以直接通过 `.length` 访问，不需要方法调用。
- `String` 是标准的 Java 类，遵循**封装**的面向对象设计原则。它的底层依赖一个内部数组（早期是`char[]`，Java 9 后优化为`byte[]`），但这个内部数组不对外暴露，而是通过 `length()` 这个公共方法间接返回内部数组的长度，对外隐藏了内部实现细节。

补充：Java 中的集合（如`List`）获取长度用 `size()` 方法，也是类的封装设计的体现。

------

### 2. 数组下标从几开始？越界会出现什么异常？

- 数组的下标（索引）**从 0 开始**。例如长度为 `n` 的数组，合法的索引范围是 `0 ~ n-1`。
- 如果访问的索引超出了合法范围（索引为负数，或大于等于数组长度），程序运行时会抛出 **`ArrayIndexOutOfBoundsException`（数组索引越界异常）**，它属于运行时异常。

------

### 3. `charAt` 能直接修改字符串里的字符吗？为什么？

**不能**。

- 从功能上：`charAt(int index)` 方法的作用只是**读取**字符串指定位置的字符，返回对应的`char`值，它本身就不具备修改功能。
- 从本质上：Java 中的 `String` 是**不可变对象（immutable）**。String 类的底层存储字符的数组被`final`修饰，且 String 类没有提供任何可以修改内部字符的方法，字符串对象一旦创建，其内容就无法被改变。

如果需要动态修改字符内容，应该使用 `StringBuilder` 或 `StringBuffer` 类，它们提供了 `setCharAt()` 等方法来修改内容。
